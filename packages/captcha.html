验证码 ​

ipiner/captcha 用于生成图形验证码，并提供统一的服务端校验流程。

安装 ​

bash
composer require ipiner/captcha
1

配置 ​

验证码配置文件为 config/pin/captcha.php。

可按需发布配置：

bash
php artisan vendor:publish --tag=pin-captcha-config
1

验证码生成 ​

Captcha::generate() 用于生成验证码及校验所需的 token。

php
use Pin\Captcha\Captcha;

$data = Captcha::generate();
1
2
3

返回示例：

php
[
    'text': 'Aj9s',
    'token': 'jCTY18DD20Y4txRyIj...',
    'width': 80,
    'height': 40,
    'data': 'data:image/png;base64,iVBORw0KGgoAAA...'
]
1
2
3
4
5
6
7
字段类型说明
textstring验证码原文，仅用于服务端校验，不应返回给客户端
tokenstring验证时提交的 token
widthint验证码图片宽度，单位为像素
heightint验证码图片高度，单位为像素
datastring验证码图片 Base64 Data URI，可直接用于 <img> 标签的 src

指定规则 ​

默认情况下，验证码使用 normal 规则进行验证，即用户输入需要与验证码原文一致。

可通过 rule 参数指定验证码规则：

php
use Pin\Captcha\Rule;

$data = Captcha::generate(Rule::Rev->value);
1
2
3

带参数的规则使用 规则名:参数 格式：

php
$data = Captcha::generate('first:2');
1

支持的规则请参阅验证码规则。

暗色模式 ​

通过 dark 参数生成适用于暗色背景的验证码：

php
$data = Captcha::generate(
    dark: true,
);
1
2
3

验证码校验 ​

验证码校验时，需要提交用户输入的验证码和生成时返回的 token。

提交格式：

text
input|token
1
  • input：用户输入的验证码
  • token：生成验证码时返回的 token

校验方法 ​

validate() ​

validate() 用于直接校验验证码，验证失败时会抛出异常：

php
use Pin\Support\Facades\Captcha;

Captcha::validate($payload);
1
2
3

verify() ​

verify() 用于校验验证码，并返回验证结果对象：

php
$result = Captcha::verify($payload);
if ($result->err === null) {
    // 验证通过
}
1
2
3
4

INFO

验证码校验默认不区分大小写。

调试输入 ​

在非生产环境中，可通过 plain: 前缀指定验证码输入内容：

text
plain:1234|token
1

验证码规则 ​

验证码规则用于定义用户输入与验证码原文之间的验证方式。

normal ​

默认规则，用户输入需要与验证码原文一致。

例如验证码为：

text
6809
1

用户输入：

text
6809
1

rev ​

倒序验证，用户输入需要为验证码原文的倒序结果。

php
$data = Captcha::generate('rev');
1

例如验证码原文为：

text
6809
1

用户输入：

text
9086
1

order:{param} ​

按照指定顺序重新排列验证码原文中的字符。

php
$data = Captcha::generate('order:2134');
1

例如：

text
验证码原文：6809
规则参数：  2134
用户输入：  8609
1
2
3

first:{n} ​

验证验证码原文的前 N 位：

php
$data = Captcha::generate('first:2');
1

例如验证码原文为：

text
6809
1

用户输入：

text
68
1

last:{n} ​

验证验证码原文后 N 位：

php
$data = Captcha::generate('last:2');
1

例如验证码原文为：

text
6809
1

用户输入：

text
09
1

prepend:{n} ​

将验证码原文中指定位置的字符添加到开头。

php
$data = Captcha::generate('prepend:2');
1

例如验证码原文为：

text
6809
1

用户输入：

text
86809
1

append:{n} ​

将验证码原文中指定位置的字符添加到末尾。

php
$data = Captcha::generate('append:2');
1

例如验证码原文为：

text
6809
1

用户输入：

text
68098
1

fixed:{value} ​

固定值验证。

该规则不依赖验证码原文，用户输入必须与指定值一致：

php
$data = Captcha::generate('fixed:abcd');
1

用户输入：

text
abcd
1

TIP

fixed 参数仅支持字母和数字。

内置路由 ​

pin.captcha.routes.enabled 用于控制是否注册验证码相关路由：

php
'routes' => [
    'enabled' => true,
],
1
2
3

默认提供：

  • GET /api/captcha：生成验证码
  • GET /api/captcha/rules：获取规则列表

如需自定义验证码接口，可关闭内置路由：

php
'routes' => [
    'enabled' => false,
],
1
2
3

缓存与一次性验证 ​

cache_enabled 用于控制验证码是否启用一次性验证，

php
'cache_enabled' => env('CAPTCHA_CACHE_ENABLED', true),
1
  • true：校验后立即失效
  • false：有效期内可重复验证
